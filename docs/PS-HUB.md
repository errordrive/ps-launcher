# PS Hub — Remote Play setup (the real way)

## 1. On your PS4 / PS5
- Settings → System → Remote Play → Enable Remote Play
- Settings → System → Power Saving → Features Available in Rest Mode → Stay Connected to the Internet + Enable Turning On PS5 from Network
- Note the console IP: Settings → Network → View Connection Status

## 2. On your phone
- Install **PS Remote Play** from Play Store (official Sony app)
- Same Wi-Fi as the console for best quality, or PSN remote over internet
- Pair controller: DualSense = hold PS + Create until blinking, then Bluetooth pair. DualShock 4 = PS + Share.

## 3. In PS Launcher
- PS Hub → enter console IP + PSN ID → Save → Launch PS Remote Play
- Tap BOOST before you start for DND + free RAM

## What NOT to expect
- No offline PS4/PS5 play on the phone, no PKG install, no disc.
- Lag depends on Wi-Fi — 5GHz, close to router, is the biggest win.
- v2 idea: Chiaki open-source client built in, so streaming stays inside PS Launcher.
